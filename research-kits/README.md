# Research Kits

Portable studies you can run yourself. Each kit holds the data or the steps to export it, the rules, a prompt for an AI chat, and a reference report to check your result against.

| Kit | Question | Reference |
|---|---|---|
| [Consecutive Bar Streaks](./Consecutive-Bar-Streaks) | After N bull or bear bars in a row, how often does the next bar continue? | ES weekly |
| [Daily Range Distribution](./Daily-Range-Distribution) | How big is a normal day, measured against the recent average range? | FDAX daily |
| [FDAX Pre-Market Breakout](./FDAX-Pre-Market-Breakout) | How often does Xetra break the overnight and pre-open ranges, and in which direction? | FDAX 15-minute |
| [Weekly Gap Close](./Weekly-Gap-Close) | How often does price trade back to last week's close, on which day, and how many weeks does it take? | ES weekly from daily RTH |
